# Iran Cities Data Analysis

A Python project for organizing geographic and population data for 10 major cities in Iran using Pandas and CSV files.

## Project Overview

This project demonstrates how to:
- Store structured data in Python.
- Create a Pandas DataFrame.
- Export data to a CSV file.
- Display city data in tabular format.

## Dataset

The dataset includes:

- `Rank`: City position in the dataset
- `City`: City name
- `Latitude`: Geographic latitude
- `Longitude`: Geographic longitude
- `Population_2026`: Population figure recorded in the dataset

**Note:** Population figures should be verified against reliable sources before being used for official or research purposes.

## Technologies

- Python
- Pandas
- CSV
- Git and GitHub

## How to Run

Install Pandas:

```bash
python -m pip install pandas
```

Run the program:

```bash
python main.py
```

The program generates `iran_cities.csv` and displays the data in the terminal.
